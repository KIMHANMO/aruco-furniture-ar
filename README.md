# 마커 위에 나타나는 3D 가구 — 쉬운 설명서

카메라에 마커를 비추고 원하는 가구를 고르면 3D 가구가 나타나고, 마우스나 키보드로 빙글빙글 돌려 볼 수 있어요.

## 설치 없이 바로 실행하기 (Windows 64비트)

1. [ArUcoFurnitureAR-win64.zip](https://github.com/KIMHANMO/aruco-furniture-ar/raw/download/ArUcoFurnitureAR-win64.zip)을 내려받아 **압축을 모두 풀어요**.
2. `A4_markers.pdf`를 실제 크기(100%)로 인쇄해요.
3. 노트북 카메라는 `run_laptop_camera.bat`, 핸드폰 카메라는 `run_phone_camera.bat`을 두 번 눌러요.
4. 3D 가구 파일은 `content/models` 폴더에 넣어요. 없으면 색깔 상자가 나와요.

- Windows가 처음 보는 프로그램이라고 막을 수 있어요. 어른과 함께 출처를 확인하고 실행해요.
- 가구 길이, 마커 크기, 카메라 값은 `settings.txt`에서 바꿔요. 저장하고 프로그램을 다시 켜면 돼요. `f` 키로 잰 카메라 값은 저절로 저장돼요.

## 코드를 고쳐서 빌드하기

1. Visual Studio 2026에 'C++를 사용한 데스크톱 개발'(v145 도구)을 설치해요.
2. OpenCV **5.0.0** Windows용을 `C:\opencv`에 풀어요. `C:\opencv\build\include` 폴더가 보이면 맞아요.
3. 환경 변수 PATH에 `C:\opencv\build\x64\vc16\bin`을 추가하고 Visual Studio를 다시 켜요.
4. `ArUco car.slnx`를 열고 **Release / x64**로 빌드해요.

## 무엇이 달라졌나요?

예전에는 마커 위에 **납작한 자동차 그림**을 붙였어요. 이제는 마커 위에 **입체 가구**가 서 있어요.

스티커와 레고를 떠올려 보세요. 스티커는 앞면만 보이지만, 레고는 돌리면 옆면과 뒷면도 보이죠? 자동차 그림이 스티커라면, 3D 가구는 레고예요.

|  | 예전 (자동차) | 지금 (가구) |
| --- | --- | --- |
| 보이는 모습 | 납작한 그림 | 입체 모형 |
| 옆면과 뒷면 | 안 보임 | 보임 |
| 돌리기 | 못 함 | 마우스와 방향키로 돌림 |
| 쓰는 파일 | PNG 그림 | OBJ 3D 모형 |

**마커**는 네모난 흑백 무늬 카드예요. 무늬마다 번호가 달라서, 컴퓨터는 어느 마커인지 구별할 수 있어요. **어떤 마커에든 원하는 가구를 골라서 띄울 수 있어요.** 하나만 띄울 때는 1번 마커만 있으면 되고, 여러 개를 함께 띄우려면 2~4번 마커를 더 놓아요.

## 어떻게 움직이나요?

컴퓨터는 아래 다섯 단계를 쉬지 않고 되풀이해요. 만화책을 빠르게 넘기면 그림이 움직이는 것처럼 보이는 것과 같아요.

1. 카메라가 사진을 찍어요.
2. 마커를 찾고 번호를 읽어요. 그 마커에 내가 고른 3D 가구를 꺼내요.
3. 마커가 얼마나 기울었는지 재요.
4. 가구를 세우고, 내가 마우스와 방향키로 돌린 각도를 더해요.
5. 화면에 색칠해요. 가까운 면을 먼 면보다 앞에 보여 줘요.

새로 생긴 부분은 4번이에요. 여러분이 돌린 각도를 컴퓨터가 기억했다가 가구에 더해 줘요.

### 3D 가구는 무엇으로 만들어졌나요?

3D 가구는 아주 많은 **삼각형 종이**를 이어 붙인 모형이에요. 삼각형이 많을수록 모양이 매끈하지만, 컴퓨터가 색칠할 것도 많아져서 느려져요.

## 3D 가구 파일 넣는 법

`content/models` 폴더에 정해진 이름으로 파일을 넣으면 끝이에요.

1. 어른과 함께 무료 3D 모델 사이트에서 가구를 고르세요. 써도 되는 작품인지 **라이선스**(사용 규칙)를 꼭 확인해요.
2. 파일 형식은 **OBJ**로 받으세요. GLB나 FBX만 있으면 무료 프로그램 Blender에서 열고 OBJ로 내보내면 돼요.
3. 압축을 풀면 보통 세 종류의 파일이 나와요. 모두 `content/models` 폴더에 넣어요.
   - `.obj` — 가구의 모양
   - `.mtl` — 가구의 색깔
   - `.png` 또는 `.jpg` — 나뭇결 같은 무늬 그림 (없을 때도 있어요)
4. `.obj` 파일의 이름만 아래 표처럼 바꿔요. `.mtl`과 그림 파일의 이름은 **바꾸지 마세요.** 서로를 이름으로 찾거든요.
5. 프로그램을 다시 켜요.

| 숫자 키 | 가구 | 파일 이름 |
| --- | --- | --- |
| 1 | 의자 (CHAIR) | chair.obj |
| 2 | 소파 (SOFA) | sofa.obj |
| 3 | 테이블 (TABLE) | table.obj |
| 4 | 침대 (BED) | bed.obj |

파일이 아직 없으면 그 자리에 **색깔 상자**가 나타나요. 고장이 아니에요! 상자로도 돌리기를 연습할 수 있어요.

가구는 진짜 크기로 나타나요. 길이를 적는 법은 ‘핸드폰 카메라로 실제 크기 보기’에 있어요. 화면에 나오는 재료와 인원은 예시로 적어 둔 값이니, 가져온 가구에 맞게 `ContentManager.cpp`에서 바꿔 주세요.

## 켜고 돌려 보기

먼저 이렇게 켜요.

1. Visual Studio에서 `ArUco car.slnx`를 열어요.
2. 위쪽 메뉴에서 **Release**와 **x64**를 골라요. Debug로 켜면 많이 느려요.
3. `Ctrl + F5`를 눌러요.
4. 마커를 바닥에 놓고 카메라로 비스듬히 내려다봐요.

### 가구 고르기

1. 1번 마커를 비춰요. `> Marker 1: empty`라고 나와요. `>`는 지금 고른 마커라는 표시예요.
2. 숫자 키를 눌러 가구를 골라요. `1` 의자, `2` 소파, `3` 테이블, `4` 침대예요.
3. 다른 숫자를 누르면 가구가 바뀌고, `0`을 누르면 사라져요.

### 여러 가구 함께 띄우기

1. 2번 마커를 옆에 놓아요. 처음 보는 마커는 저절로 골라져요.
2. 숫자 키로 가구를 골라요. 같은 가구를 또 띄워도 돼요.
3. 3번, 4번 마커도 똑같이 해요. 한 번에 네 개까지 띄울 수 있어요.
4. 다른 마커를 고르려면 그 마커를 마우스로 눌러요.

| 하고 싶은 일 | 마우스 | 키보드 |
| --- | --- | --- |
| 마커 고르기 | 마커를 클릭 | 없음 |
| 가구 띄우기·바꾸기 | 없음 | 1 ~ 4 |
| 가구 치우기 | 없음 | 0 |
| 팽이처럼 돌리기 | 누른 채 왼쪽·오른쪽으로 끌기 | ← → |
| 앞뒤로 기울이기 | 누른 채 위·아래로 끌기 | ↑ ↓ |
| 모든 가구 처음 모습으로 | 없음 | r |
| 크게 / 작게 (100%가 실제 크기) | 없음 | + / - |
| 사진 저장 | 없음 | c |
| 이름표 켜고 끄기 | 없음 | i |
| 가구 정보 켜고 끄기 | 없음 | s |
| 마커 테두리 켜고 끄기 | 없음 | d |
| 끝내기 | 없음 | q 또는 Esc |

방향키를 한 번 누르면 약 6도씩 돌아가요. 60번쯤 누르면 한 바퀴예요.

## 핸드폰 카메라로 실제 크기 보기

마커는 **자** 역할을 해요. 컴퓨터는 마커의 진짜 길이가 180mm(18cm)라는 걸 알고 있어요. 그래서 900mm 책상은 마커의 5배 길이로 그리면 실제 크기가 돼요.

### 1. 마커 인쇄하기

1. 폴더에 있는 `A4_markers.pdf`를 열어요. 한 장에 마커가 하나씩, 모두 네 장이에요.
2. 인쇄 설정에서 **실제 크기(100%)** 를 골라요. ‘용지에 맞춤’을 고르면 마커가 작아져서 가구 크기가 틀려요.
3. 아래쪽 선을 자로 재요. 정확히 10cm이면 성공이에요.
4. 검은 네모의 한 변이 180mm가 아니면, 잰 길이를 `settings.txt`의 `markerMm`에 적어요.

### 2. 핸드폰을 카메라로 연결하기

1. 어른과 함께 핸드폰을 컴퓨터의 웹캠으로 연결해요. 안드로이드는 Windows 11의 모바일 장치 설정에 있는 ‘연결된 카메라’ 기능을 쓸 수 있어요. 아이폰은 웹캠 앱이 따로 필요해요.
2. 핸드폰을 **가로**로 들어요.
3. 프로그램을 켤 때 카메라 번호를 알려 줘요. 노트북 카메라는 보통 0번, 핸드폰은 1번이에요. Visual Studio에서 프로젝트 속성 → 디버깅 → 명령 인수 칸에 `1`을 적어요. 안 나오면 `2`를 적어 봐요.

### 3. 카메라 눈 맞추기 (한 번만)

카메라마다 보이는 넓이가 달라서 한 번 재 줘야 해요.

1. 마커 한 장을 벽에 붙여요.
2. 핸드폰을 마커에서 정확히 **1m** 떨어진 곳에 두고, 똑바로 마주 봐요.
3. `f` 키를 눌러요. 화면에 `focalRatio = 0.8`처럼 숫자가 나와요.
4. `saved`라고 나오면 `settings.txt`에 저절로 저장된 거예요. 핸드폰의 확대(줌)를 바꾸면 다시 재야 해요.

### 4. 가구의 진짜 길이 적기

3D 파일에는 진짜 길이가 정확히 들어 있지 않을 때가 많아요. 가구의 **가장 긴 변**을 mm로 찾아서 `settings.txt`에 적어요.

| 가구 | 지금 적힌 가장 긴 변 (예시) |
| --- | --- |
| 의자 | 850mm |
| 책상 | 1200mm |
| 소파 | 1900mm |
| 침대 | 2000mm |

예를 들어 `chair = 850`에서 `850`을 바꾸고 프로그램을 다시 켜면 돼요. 나머지 두 변은 모양에 맞춰 저절로 정해지고, 화면 오른쪽에 나타나요.

### 5. 바닥에 놓고 보기

마커를 **바닥**에 평평하게 놓고 1\~3m 떨어져서 비스듬히 봐요. 위쪽에 `Size 100%`라고 나오면 실제 크기예요. 너무 가까우면 가구가 화면을 꽉 채우니 뒤로 물러나요.

## 코드 속 일꾼들

프로그램은 여러 일꾼이 일을 나눠 맡은 놀이공원과 같아요. 일꾼마다 파일이 하나씩 있어요.

| 일꾼 (파일) | 하는 일 | 이번에 바뀐 점 |
| --- | --- | --- |
| Mesh | 3D 가구 파일을 읽는 **조립사** | 새로 들어왔어요 |
| AROverlay | 마커 위에 가구를 그리는 **화가** | 납작한 그림 대신 입체를 그려요 |
| ContentManager | 가구 목록을 정리하는 **사서** | 자동차 4대가 가구 4개로 |
| UIManager | 글자를 쓰고 조작을 듣는 **안내원** | 마우스, 방향키, 숫자 키를 알아들어요 |
| ARCardService | 모두에게 일을 시키는 **대장** | 마커마다 고른 가구와 돌린 각도를 기억해요 |
| Settings | 설정 파일을 읽고 쓰는 **비서** | 새로 들어왔어요 |
| MarkerDetector | 마커를 찾는 **탐정** | 그대로 |
| MarkerInfo | 마커의 번호와 위치를 적은 **메모지** | 그대로 |
| CameraManager | 카메라를 켜는 **사진사** | 그대로 |
| main | 프로그램을 시작하는 **스위치** | 그대로 |

`tests/selfcheck.cpp`는 카메라 없이 가구 읽기와 그리기를 검사하는 시험지예요.

가구를 더 넣고 싶으면 `ContentManager.cpp`에서 `{ "BED", ... }` 부분을 복사해 이름, 파일 이름, 길이를 바꾸면 돼요. 다음 숫자 키가 저절로 붙어요(최대 9개).

## 잘 안 될 때

| 이런 일이 생기면 | 이렇게 해 보세요 |
| --- | --- |
| 마커를 비춰도 아무것도 안 나와요 | 창을 한 번 클릭하고 숫자 키 1~4로 가구를 골라요 |
| 가구 대신 상자가 나와요 | `content/models` 폴더에 파일이 있는지, 이름이 `chair.obj`처럼 맞는지 봐요 |
| 가구가 회색이에요 | `.mtl` 파일과 무늬 그림을 같은 폴더에 넣어요. 파일 이름은 영어로 해요 |
| 가구가 누워 있어요 | 위·아래 방향키로 세워요. 모델을 만든 사람이 눕혀서 저장한 거예요 |
| 가구의 머리 꼭대기만 보여요 | 마커를 카메라 정면으로 들고 있어서 그래요. 바닥에 놓거나 위로 끌어 기울여요 |
| 화면이 뚝뚝 끊겨요 | Release로 켜요. 그래도 느리면 삼각형이 1만 개쯤인 가벼운 가구로 바꿔요 |
| 가구가 떨리거나 기울기가 휙 바뀌어요 | 마커를 더 크게 인쇄하고, 밝은 곳에서 조금 비스듬히 비춰요 |
| 가구 키가 너무 길거나 짧아요 | `settings.txt`의 `focalRatio` 값이 카메라와 안 맞아요. 1m 거리에서 f 키로 다시 재요 |
| 방향키가 안 들어요 | 가구가 보이는 창을 한 번 클릭해요 |
| 카메라가 안 켜져요 | 다른 프로그램이 카메라를 쓰고 있으면 꺼요 |
